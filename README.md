# Web Dev's Max — Combined Portfolio

This version combines the strongest structural and visual ideas from the two supplied portfolio files:

- Claude version: terminal/developer aesthetic, dark-first UI, skills, featured work, theme control and concise project presentation.
- ChatGPT version: loader, personal-brand hero, founder positioning, company section, Hire Me CTA and portfolio-style presentation.

## Run

Open `index.html` in a browser. No build step is required.

Replace the generated initials avatar in `index.html` with your real profile image when you are ready.
